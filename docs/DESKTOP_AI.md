# Desktop AI Compatibility

NovelFlow uses capabilities instead of hard-coding vendors.

- Tier A: MCP clients — configure `novelflow-mcp`.
- Tier B: terminal-capable agents — call `novelflow` CLI.
- Tier C: file/editor agents — read AGENTS.md and edit result files, with a human running state commands.
- Tier D: pure chat — copy `novelflow prompt` output in/out manually.

Included instruction surfaces: AGENTS.md, CLAUDE.md, GEMINI.md, Cursor rules, Windsurf rules, Cline rules, Copilot instructions and Aider config.
